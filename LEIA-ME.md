# Pacote Windows pronto para rodar

Baixe **`Diarios-Oficiais-Windows.zip`** (botão *Download raw file* na página do arquivo),
extraia **tudo** e dê dois cliques em **`ABRIR_PAINEL.bat`**. O Java já vem dentro (OpenJDK 21,
Windows 64 bits); não precisa instalar nada. Detalhes no `LEIA-ME.txt` de dentro do zip.

Este branch só existe para guardar o zip; pode ser apagado depois de baixar.
